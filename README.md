# Doomsday Décompte

Calendrier de 15 cases + compte à rebours avant **Avengers: Doomsday** (PWA installable).

- Modifier les titres/liens et les dates dans `videos.js`.
- Une case se débloque chaque jour à minuit (heure locale) à partir de `CONFIG.DEBUT`.
- Déployé automatiquement sur GitHub Pages à chaque push sur `main`.
